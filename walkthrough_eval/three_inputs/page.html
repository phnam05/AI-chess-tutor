How far this goes

  • Two positions, one answer per version. Gemini's wording changes from run to run.
  • Both positions were picked by hand, and both are a hanging piece, the kind of mistake the board facts are built to see. A positional mistake, where no board fact applies, is not tested here.
  • Version B uses version C's instructions with the board-fact rules taken out, so the difference between B and C is the facts plus the rule to use only them.
  • Our automatic checker passed all six answers, including both wrong ones from A. A wrong reason can only be caught by a person, or by a stronger judge.
  • Next: the same comparison on new positions, more cases and positional mistakes.
